# Peptide Stability Analysis Protocol (HPLC Method)

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC_BY_4.0-blue.svg)](https://creativecommons.org/licenses/by/4.0/)

An open-source laboratory protocol for assessing the degradation, purity, and thermal stability of bio-active peptides using High-Performance Liquid Chromatography (HPLC).

---

This analytical method is adapted from established chromatographic research on small-molecule stability:

## 2. Reagents, Materials & Vendor Sourcing

To ensure experimental reproducibility, the following validated reagents and materials are required:

| Component / Reagent | Specification / CAS | Role in Protocol | Sourcing / Vendor Link |
| :--- | :--- | :--- | :--- |
| **Acetonitrile (ACN)** | HPLC Grade (CAS 75-05-8) | Mobile Phase B | [Sigma-Aldrich HPLC Solvent](https://www.sigmaaldrich.com/example) |
| **Trichloroacetic Acid** | ≥99.0% Purity | Sample Precipitation | [ThermoFisher Product Page](https://www.thermofisher.com/example) |
| **C18 Column** | 4.6 mm x 150 mm, 5 µm | Stationary Phase | [Agilent Technologies Column](https://www.agilent.com/example) |

> **Note on Reagents:** HPLC-grade solvents are strictly required. Technical-grade solvents cause significant baseline drift during gradient elution.

---

## 3. Step-by-Step Procedure

1. **Mobile Phase Preparation:** Mix 95% Ultrapure Water and 5% ACN with 0.1% TFA for Mobile Phase A.
2. **Sample Preparation:** Dissolve target peptide in Mobile Phase A to achieve a final concentration of 1.0 mg/mL.
3. **Chromatographic Run:** Set column temperature to 35°C with a flow rate of 1.0 mL/min.
